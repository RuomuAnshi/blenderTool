# 角色特效：脸红、水渍、油、沐浴露（意味深）

## 基础效果

- **脸红**：自动识别脸部材质，用静止网格比例生成双颊遮罩，或使用自定义灰度遮罩。
- **水渍**：沿皮肤表面生成有体积的透明液体流痕，包含贴肤底面、弧形液面、宽窄变化和局部积水末端。默认只处理身体和颈部皮肤。流痕按重力方向沿源网格本地 −Z 投射，复制骨骼权重并随同一骨架变形；作为原角色的独立子对象生成，可整体移除。
- **油**：独立的连续平滑亮膜，保留皮肤底色并叠加油光。默认只处理身体和颈部皮肤，可调整亮度与柔和度。
- **沐浴**：学习自瑞鵆的沐浴露节点

三种效果各自添加、更新、移除。水渍与油可叠加，分别移除；默认跳过衣物、头发和眼睛。材质自动识别，不依赖活动材质槽。识别例外时，可在高级设置中指定额外材质。

## 基础妆造（1.6）

选中角色主网格，在“角色特效 → 基础妆造”点击“添加／更新妆造”。眼影与口红各自支持开关、颜色、浓度；应用后保持该网格激活，修改参数会直接更新。移除妆造会恢复原颜色连接，并保留脸红等其他效果。

默认自动识别脸部材质，沿用脸红的正面方向与额外脸部材质设置。首次应用尝试根据脸部网格的眼睛、嘴部开口定位，无法识别时使用比例默认值。不同模型的拓扑、眼型和嘴型不同，自动结果需要时在高级设置中微调眼影间距、高度、宽度、纵向范围，以及口红高度、宽度、纵向范围；“自动定位眼唇”会重置这些位置参数。默认遮罩基于静止脸部坐标，随原网格表情变形，无需新增液体或妆容网格。

精细妆容可分别指定眼影、口红灰度遮罩（白色上妆，黑色保留原色）及遮罩 UV。基础妆造通过原着色器 Base Color 混色，支持 Principled 与提供 Base Color 的 Toon 节点组；目前不包含独立唇蜜、珠光或亮片材质。


## 下载安装

适用于 **Blender 5.2 及以上**。在 [GitHub Releases](https://github.com/RuomuAnshi/blenderTool/releases/latest) 下载 `blenderTool-v1.6.0.zip`（不要选 Source code），无需解压。

1. Blender → 编辑 → 偏好设置 → 插件 → 右上角菜单 → **从磁盘安装**。
2. 选择 ZIP，安装后启用 Character Effects／角色特效与妆造。
3. 选中角色主网格，在 3D 视图按 `N` → **角色特效**。

附件 ZIP 的根目录包含扩展清单、插件入口和打包资源，可直接安装。`SHA256SUMS.txt` 用于校验下载文件。源码开发者可运行 `python3 scripts/build_addon.py` 构建相同安装包。
