# 角色特效：脸红、水渍、油、沐浴露

独立 Blender 5.2+ 插件。脸红和水渍基于 `zeldaRender` 提取后重构，油使用独立连续亮膜着色器。

## 基础效果

- **脸红**：自动识别脸部材质，用静止网格比例生成双颊遮罩，或使用自定义灰度遮罩。
- **水渍**：沿皮肤表面生成有体积的透明液体流痕，包含贴肤底面、弧形液面、宽窄变化和局部积水末端。默认只处理身体和颈部皮肤。流痕按重力方向沿源网格本地 −Z 投射，复制骨骼权重并随同一骨架变形；作为原角色的独立子对象生成，可整体移除。
- **油**：独立的连续平滑亮膜，保留皮肤底色并叠加油光。默认只处理身体和颈部皮肤，可调整亮度与柔和度。

三种效果各自添加、更新、移除。水渍与油可叠加，分别移除；默认跳过衣物、头发和眼睛。材质自动识别，不依赖活动材质槽。识别例外时，可在高级设置中指定额外材质。

## 安装与使用

1. 将 `character_effects` 文件夹打包为 zip，通过 Blender 的 **偏好设置 → 插件 → 从磁盘安装** 安装并启用。
2. 激活角色网格，在 3D 视图按 `N`，打开 **角色特效** 标签。
3. 调整相应强度，点击 **添加／更新**；关闭时点击对应的 **移除**。
4. 高级设置提供水渍数量、长度、宽度、积水厚度、液面粗糙度、折射强度、随机种子，以及油光参数、额外材质和灰度遮罩。参数变化后点击添加／更新生效。

自动脸红默认本地 −Y 为正面，Z 为竖直轴。水渍和油默认排除脸部，可各自在高级设置开启。开启脸部水渍时，自动使用更细、更薄的短流痕，限制流痕越过下颌，并平滑减弱轮廓处高光，避免形成碎白边；脸部正面方向沿用脸红的正面设置。自定义灰度遮罩中白色允许效果，黑色保护；遮罩的 UV 留空时使用活动 UV。水渍遮罩按源网格 UV 采样，黑色遮罩不会生成液体。

水渍形态是静态流痕，随骨骼移动；不会进行流体模拟，也不复制角色的形态键。厘米／毫米尺寸按场景单位和物体缩放换算。材质使用水的 IOR 1.333；为兼容当前 Toon 工程，默认以透明液面结合少量折射显示，较高折射强度需要底层角色材质和渲染器支持。油的亮条取决于灯光形状，增大光源或提高油光柔和度可柔化亮膜。

## 沐浴露（1.5）

独立的“沐浴露”功能使用流淌覆盖贴图与对应法线表现局部黏稠液体。默认只勾选身体与颈部皮肤；可分别勾选脸部、头发、衣服，然后点击添加／更新。取消部位后再次更新，会移除该部位之前添加的沐浴露。移除按钮清除当前网格全部沐浴露，不依赖当前范围开关。

高级设置支持密度、位置、粗糙度、高光、不透明度、凸起强度、额外材质及局部灰度遮罩。贴图使用模型 UV；不同模型的 UV 方向、接缝会影响流痕方向与大小，可调整密度与位置。材质名称自动识别存在例外时，指定额外材质，或通过材质自定义属性 `bt_effect_role` 指定 `SKIN`、`FACE`、`HAIR`、`CLOTHES`。脸部使用较柔和的法线、高光及轮廓衰减。

原节点和贴图来自用户提供的《沐浴露节点 by瑞鵆.blend》，作者：瑞鵆。保留于 `assets/bath.blend`，贴图已打包，无需原 NAS 路径；移除了示例 MMD 材质与球面贴图依赖，并适配原角色着色器混合。该第三方资源不属于本项目 MIT 代码授权范围，权利归原作者。
